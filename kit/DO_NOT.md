# DO_NOT — batas keras

Disalin ke `~/bounty/state/DO_NOT.md` di VM saat bootstrap. Kalau dua aturan bertabrakan, yang di sini
menang atas kebiasaan.

## Uang & efek samping

- Jangan membeli apa pun dengan uang nyata tanpa bertanya (termasuk langganan, deposit, gas mainnet).
- Jangan mengirim email ke pihak luar tanpa Jun melihat drafnya.
- Jangan menghapus atau menimpa file di luar folder target.
- Jangan menjalankan `git push --force`, reset repo, atau hapus branch tanpa sebut.
- Jangan mengubah setelan akun (email, password, 2FA, hapus device) tanpa sebut.

## Data

- Jangan menulis ke data user lain; baca seperlunya lalu hapus salinannya.
- Jangan menempel nilai rahasia utuh di chat atau file yang akan dibagikan.
- Jangan mengunggah file target ke layanan pihak ketiga tanpa alasan.
- Jangan menyentuh akun orang lain tanpa izin tertulis.

## Produk Muse

- Jangan `Reset` Muse tanpa backup `state/backup/`.
- Jangan mengubah `Soul.md` di tengah pekerjaan untuk menyesuaikan kandidat; catat, selesaikan, baru ubah.
- Jangan memasang tool system-wide di VM tanpa mencatat di CHANGELOG.

## Klaim

- Jangan bilang "terkirim", "selesai", "berhasil" tanpa memeriksa bukti (Activity log, output, hash).
- Jangan menyebut severity tanpa baris program yang mendukung.
- Jangan menutup target karena merasa tidak produktif.
